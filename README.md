## ✨ Sobre o projeto

Aplicação de página única (SPA) construída em **React** que reúne, em um só lugar:

- 🏠 **Início** — apresentação e atalhos para minhas redes.
- 👨‍💻 **Sobre mim** — minha trajetória como desenvolvedor Full-Stack.
- 🚀 **Projetos** — uma vitrine dos principais projetos, com links para a demo e o código.
- 📄 **Currículo** — meu CV disponível para visualização direta no navegador.

O site é totalmente **responsivo**, com menu adaptado para mobile, e é publicado automaticamente no **GitHub Pages** a cada push na branch `master`.

> 🔗 **Acesse:** [thalesdferreira.github.io](https://thalesdferreira.github.io/)

## 🚀 Como rodar localmente

> Requer **Node.js 16** instalado.

```bash
# 1. Clone o repositório
git clone https://github.com/ThalesDFerreira/ThalesDFerreira.github.io.git

# 2. Entre na pasta do projeto
cd ThalesDFerreira.github.io

# 3. Instale as dependências
npm install

# 4. Rode em modo de desenvolvimento
npm start
```

A aplicação abrirá em [http://localhost:3000](http://localhost:3000).

| Comando         | Descrição                                      |
| --------------- | ---------------------------------------------- |
| `npm start`     | Inicia o servidor de desenvolvimento           |
| `npm run build` | Gera a versão de produção em `/build`          |
| `npm test`      | Executa os testes                              |
| `npm run lint`  | Verifica o código com o ESLint                 |
